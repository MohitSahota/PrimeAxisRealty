# Prime Axis Realty

Prime Axis Realty is a premium real estate platform built with Next.js, designed to showcase luxury residential, commercial, and investment properties across Chandigarh, Mohali, Panchkula, Zirakpur, New Chandigarh, Kharar, and Derabassi.

The website focuses on modern design, fast performance, strong SEO, mobile responsiveness, and lead generation for the Tricity real estate market.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/prime-axis-realty.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## Build for Production

```bash
npm run build
```

Run production server:

```bash
npm run start
```
